What is not known

Each of these needs the device or another browser:

  1. Real-device performance. Frame rate, dropped frames, the Chapter 3 transition timing and thermal behaviour. SwiftShader frames saturate at 100 ms, so there is no valid frame-time evidence. Built-in safeguard: the runtime monitor judges the first 1–3 s of motion and drops to the lighter tier, then to the static spreads, if the device is too slow. It does not react to a slowdown later in the session, for example thermal throttling. The static spreads are fully tested.
  2. Page-edge accuracy on a real GPU (Mali). Low risk: the shader uses highp and the CPU copy matches float32 exactly. The 2.23 px sample comes from the edge algorithm's own row-switching, not from the GPU.
  3. Touch feel. Scrolling, the address bar showing and hiding, the on-screen keyboard, pinch zoom.
  4. TalkBack speech, and the Android back gesture with the menu open. The accessibility tree is verified; the spoken output is not.
  5. Rotation position (open risk). In emulation, rotating at the Chapter 3 rest moved the scroll position to the end card (380 → 865 vh). Real Chrome may keep the place by scroll anchoring. Unconfirmed.
  6. iOS / Safari and Samsung Internet. Not tested in any form. WebKit was never run.

Release blockers

For provisional approval: none.

Before any public release (must be resolved):

  1. Real-device evidence on at least one mid-range Android (the A26) and one iPhone. A short smoke subset is enough; see below.
  2. Rotation position confirmed on a device. If it jumps, a small, contained fix: keep the chapter-relative position across an orientation change.
  3. Approved content: copy, Chapter 3 portrait photography and the logo file. All are marked placeholders today.
  4. A short manual screen-reader pass (TalkBack, and VoiceOver on the iPhone).
  5. Hosting and deployment approval. The site exists only as a private preview.

Watch items (not blockers):

  • The edge max of 2.23 px leaves the thinnest margin under the 3 px limit.
  • TalkBack's focus outline can sit over the current picture while it reads chapter text that has not scrolled into view.
  • The density-matched still (I6) remains undecided.
  • Start-up long tasks are unattributed; that needs a connected-device trace.
